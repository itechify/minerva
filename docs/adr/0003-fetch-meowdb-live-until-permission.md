# Fetch map data live from MeowDB; get permission before public release

Map data was fetched from MeowDB on a confirmed map change, cached as Saved Copies, and credited with an honest user agent; public release required permission. ADR-0008 replaced map and mob fetching with OSMS Data Explorer's files and lifted that release restriction. Saved Copies, the honest user agent and credit still hold for Item Lookup's MeowDB search (ADR-0007).
